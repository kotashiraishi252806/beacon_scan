# 接続試行回数の定義

## 結論

**接続試行回数 = `requestNetwork` 呼び出し回数** と見なせる。

## 根拠

`requestNetwork` は `SupplicantMeasurer.kt` の `measureForAp()` 内（181行目）で **APごとに1回だけ** 呼ばれる。

## 例外（`requestNetwork` が呼ばれないケース）

| `supplicantFinalState` | 理由 |
|---|---|
| `SKIPPED` | `buildSpecifier()` が `null` を返した場合（WEP AP、または不正なBSSID） |
| `CANCELLED` | `stopRequested = true` になった後のAP（`measureAll()` 内で `measureForAp()` 自体をスキップ） |

`SKIPPED` と `CANCELLED` 以外の finalState を持つAPは全て `requestNetwork` が1回呼ばれている。
