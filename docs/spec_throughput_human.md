# スループット測定モード — 概要説明書

## このモードでできること

Wi-Fi（無線LAN）の通信速度（スループット）をボタン1つで測定できるモードです。

測定すると、以下の情報がまとめて自動的に取得・記録されます。

| 取得する情報 | 説明 |
|---|---|
| 現在地（緯度・経度） | GPSを使って測定した場所を記録する |
| Wi-Fiネットワーク名（SSID） | 接続中のWi-Fiの名前 |
| 電波強度（RSSI） | Wi-Fiの電波がどれくらい強いか（単位: dBm） |
| 通信規格 | 802.11n / 802.11ac / 802.11ax など |
| 通信速度（スループット） | 実際のダウンロード速度（単位: Mbps） |
| 測定時間 | ダウンロードにかかった時間（単位: 秒） |
| ダウンロードファイルサイズ | ダウンロードしたデータの量（単位: MB） |

取得したすべてのデータは自動的にサーバへ送信されます。

---

## 使い方（操作手順）

1. アプリを起動し、モード選択画面から「スループット測定」を選ぶ
2. **測定ファイルを選ぶ**（プルダウンメニューから選択）
   - ファイルが大きいほど精度の高い測定ができるが、時間がかかる
3. **送信先サーバを選ぶ**（プルダウンメニューから選択）
   - 一覧にないサーバに送りたい場合は「自分で入力」を選んでURLを手入力する
4. 「**測定開始**」ボタンを押す
5. 測定が終わると、画面に結果が表示される
6. 何度でも繰り返し測定できる（測定回数が画面に表示される）

---

## 測定中に何が起きているか

「測定開始」ボタンを押すと、アプリは以下を順番に自動で行います。

```
① 現在地を取得（GPSを使用）
       ↓
② Wi-Fi情報を取得（SSID・電波強度・通信規格）
       ↓
③ 速度を測定（指定したファイルをダウンロードして速度を計算）
       ↓
④ 測定結果をサーバに送信
       ↓
⑤ 画面に結果を表示
```

①〜④のいずれかで問題が発生した場合は、その時点で測定を中断してエラーを表示します。

---

## サーバに送信されるデータの例

測定結果は以下のような形式でサーバに送られます（JSON形式）。

```json
{
  "latitude": 34.6851,
  "longitude": 135.8469,
  "ssid": "MyWiFi",
  "rssi": -55,
  "wifistandard": "802.11ax",
  "downloadfilesize": 5,
  "measure_time": 1.234,
  "throughput": 32.45
}
```

---

## 注意事項

- **Wi-Fiに接続していない状態では測定できません。**
- **初回起動時に「位置情報へのアクセスを許可しますか？」というダイアログが表示されます。「許可」を選んでください。** Wi-FiのSSIDを取得するためにも位置情報の許可が必要です（Androidの仕様）。
- 測定のタイムアウトは **5秒** です。回線が非常に遅い場合は5秒時点までに取得できたデータで速度を計算します。
- 測定中はボタンが押せなくなります（二重測定の防止）。
